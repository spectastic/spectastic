What's coming up

A live list of unrouted items, the small things that don't need a spec, and what's deferred.

Status Active Owner Brian Corbin · @briancorbinxyz Updated 12 Jun 2026 Read time

The small-batch entry point. Paste a list of items into /spectastic.triage and one <spec-triage> card lands here per item, with the layer= attribute set to one of the routing exits. /spectastic.implement drains the just-do queue one at a time. Use this for cross-cutting fixes, typos, small UI tweaks, and anything that doesn't fit cleanly inside a single spec's triage log.

1 · Card states

Unrouted
No layer= attribute yet. Just-captured items. Needs classification.
Just-do
layer="just-do". Small enough that a spec would not change the decision — one file, no public-contract change, revert-safe. Implement immediately; no proposal.
Defer
layer="defer". Back-burner. Carries defer-to= pointing at a sibling spec ID, TBD, or never.
Routed to a layer
layer="spec" | plan | implementation | cross-spec | principles | platform. The item became (or needs to become) a spec change-proposal or constitutional amendment.

Once a just-do card is implemented, it gets data-status="done" and stays in the inbox as history — strikethrough, faded, with a DONE pill.

Implement command lacks drain / phase / parallel modes

Spec upstream

Expected
