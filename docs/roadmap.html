1 · How to read this

Two roadmap views exist, and they answer different questions:

028 build-order view
Generated (spectastic order, do not hand-edit). Ranks the committed spec corpus so nothing precedes a spec it depends on. It knows only about specs — it cannot show deferred ideas that have no spec yet.
This page
Hand-maintained. Tracks the considerations-doc backlog — the TBD-* moves each research doc recommended, checked off as they land. When a TBD graduates into a spec, it moves into the 028 view.

Ordering here is RICE, lifted from the roadmap-ranking portfolio synthesis. RICE is a value estimate, not a dependency graph — a lower-scored item may still need to precede a higher-scored one (e.g. the artifact-security spec precedes its own CI check). Read the score as "how much this is worth", not "build this first regardless".
