1 · The grid

Axes resolve in the order they are declared — mode, then platform, then size class. There is no order attribute: a number could disagree with the markup, and then a reader would have to know which one wins.

The grid is combinatorial and most cells are uninteresting, so only interesting ones are written down. A cell that is absent means nobody looked. A cell somebody looked at and found identical is recorded below as such, so silence never has to carry two meanings.

Selects token values only.

Selects values, component set and input model — which is why it is an axis and not a theme. A focus-driven remote and a pointer are different ways of operating the same screen.

A converter is entered a digit at a time and read once. On a focus-engine remote that is worse than useless, and nobody asked for it. Declined explicitly so the grid records a decision rather than an omission.
