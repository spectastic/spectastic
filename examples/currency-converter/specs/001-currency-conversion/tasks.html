Currency conversion

Ordered, parallelizable work. Tests precede implementation. Drive through with /spectastic.implement — one task per invocation.

Status Accepted Spec 001-currency-conversion Design design Branch 001-currency-conversion Created 06 Aug 2026 Read time

16 tasks across five phases. Setup → Foundational → User stories (US1·US2·US3) → Polish. Tasks marked [P] can run in parallel — different files, no dependency. Tests for a story MUST be written and failing before its implementation tasks start.

 Illustrative artifact. Part of a worked exemplar for the visual-spec survey. The tasks describe work on a fictional app. T-401 and T-402 reference a fidelity check that does not exist and is governed by TBD-fidelity-measurement.

1 · Execution strategy

Implement US1 end-to-end against a single hard-coded pair. Ship. Add US2 and US3 after.

Setup → Foundational → US1 → US2 → US3 → Polish. Each story closes its conformance before the next opens. Chosen — the state machine is shared, so parallel stories would collide in one file.

Not viable here. All three stories render from one view and one state machine.

2 · Phase 1 — Setup

Generate the rates client — from the declared contract. Sources/Converter/RatesClient.swift
Wire in the token set — so tokens resolve per mode. Sources/Converter/Tokens.swift

3 · Phase 2 — Foundational

Test the Rate invariant — a Rate cannot be constructed without an observation time. Tests/ConverterTests/RateTests.swift
Add the value types — Rate and Conversion, Decimal ratio, non-optional asOf. Sources/Converter/Rate.swift
Build the rate cache — with a synchronous read path. Sources/Converter/RateCache.swift

Implements D-001. The synchronous read is what makes NFR-001 a property of the architecture.

4 · Phase 3a — US1 · Convert an amount

Tests

Test state coverage — every one of the ten states is reachable and renders. Tests/ConverterTests/StateCoverageTests.swift
Test the latency ceiling — conversion renders from cache within 100 ms of a keystroke. Tests/ConverterTests/LatencyTests.swift

Implementation

Build the converter view — amount field, pair picker, converted figure. Sources/Converter/ConverterView.swift
Add the state machine — over cache contents and the last request outcome. Sources/Converter/ConverterState.swift

Closes FR-001, NFR-001, SC-002.

5 · Phase 3b — US2 · Judge whether the rate is current

Tests

Test staleness — it fires past the window and stays legible in greyscale. Tests/ConverterTests/StalenessTests.swift

Implementation

Add the staleness badge — text plus the warning token, keyed on asOf. Sources/Converter/StalenessBadge.swift

Closes FR-002, SC-001.

6 · Phase 3c — US3 · Keep working when the network does not

Tests

Test the offline path — offline retains the figure; cold-start does not invent one. Tests/ConverterTests/OfflineTests.swift

Implementation

Add the network states — offline, cold-start, and the mapping for the six error responses. Sources/Converter/ConverterState.swift

Closes FR-003, FR-004, FR-005.

7 · Phase 4 — Polish

Test the accessibility floor — layout holds at the largest Dynamic Type size and tap targets meet 44 pt. Tests/ConverterTests/AccessibilityTests.swift
Snapshot per state and mode — view descriptions rather than images. Tests/ConverterTests/SnapshotTests.swift
Assert telemetry stays off — no event is emitted while consent is unanswered. Tests/ConverterTests/TelemetryTests.swift
Run the fidelity pass — against the declared token set, on iOS and iPadOS. Tests/ConverterTests/FidelityTests.swift
Verify the macOS baseline — declared in the variant grid and never checked. Tests/ConverterTests/FidelityTests.swift

Closes NFR-002, NFR-003, SC-003. T-503 and T-504 are unchecked because the fidelity pass they depend on does not exist — they are the two tasks this exemplar cannot honestly tick.
