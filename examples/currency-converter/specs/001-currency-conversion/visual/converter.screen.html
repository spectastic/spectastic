2 · What this screen reports, and what gates it

The plan is authored now so that answering the consent question is a switch rather than a retrofit. Nothing ships until it is answered, and nothing here causes an event to be emitted — a declaration is a design decision and never evidence that a build does anything.

3 · The route through it

A converter is two screens and a return. The branch is the half usually left unwritten: dismissing the picker without choosing is the common case, and it is not an error.

The currency picker. A sheet rather than an inline control, because the list is long enough to need search.

The full list, with the current pair pre-selected.

 The sheet is dismissed without a choice. The amount stands, the pair is unchanged, and no request is made — a return rather than a failure. No request left the device. The last known figure stays on screen, marked stale rather than cleared. Leaves for the system share sheet, which this feature does not own.

4 · The controls, and what they do

A component's states are driven by interaction — there is no status code for hover — which is why they live here rather than on each screen that uses the control.

The default: filled, with the accent token. Not reachable by touch; present for the pointer platforms. A two-point ring outside the fill, so it survives against the accent. Fill darkens; no scale change, which reads as lag on a slow device. Uses aria-disabled rather than disabled, so it stays focusable and can explain why it is unavailable. Label replaced by a spinner after 150 ms, not immediately — a flash on a fast response is worse than nothing. The result appears in the figure above; a success state on the button would be a second announcement of one event. Errors belong to the rate line, which is where a reader is already looking. A button has no content of its own to be empty of.

5 · What moves, and when

One element changing is a token. This is a sequence, and no token expresses an order.

Skipped entirely. The figure and the rate line change to their new values on the next frame, with no cross-fade and no movement. Nothing is lost — the transition carries no information the values do not.

6 · What may be written, and what may not

The layout is designed against copy of a particular length, and the copy usually arrives later from somebody who never saw the layout. None of this is checked against real strings — they live in a localisation system this vocabulary cannot see, and a partial check would report clean while the rest overflowed.

It names no cause and offers no action, and on this screen there is always something to say — the figure shown is either current or stale, and which one it is matters. Fine in a log line and useless on screen. Scoped rather than blanket, because the word is not the problem — the placement is.
