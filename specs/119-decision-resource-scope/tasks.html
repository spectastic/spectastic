1 · Execution strategy

Foundational (types, grammar, parse) → owner-aware verdict (tests then code) → validate rule → estate/build check. The default for this slice — the spike already did the risky discovery.

The four owner/non-owner fixtures and the no-network scan fail first; then the owner-aware branch. The validate-rule fixtures fail before the rule exists.

2 · Phase 1 — Setup

No setup — no new dependencies, no scaffolding, no CI bootstrap. Work begins at Foundational.

4 · Phase 3a — US1 + US2 · The owner-aware verdict

Tests (write & fail first)

The four owner/non-owner scenarios — assert the verdict against a resource-scoped decision with a fixture currentProject: owner-outside-allowed-in flags (A), owner-inside is clean (B), a non-owner touch flags (C), and a well-layered write in a non-owner's own adapter still flags (D). Assert a path-scoped decision is unchanged (back-compat). packages/core/test/guardrail.verdict.resource.test.ts
Purity holds with the new branch — extend the no-network import scan so the owner-aware verdict path carries at most 0 filesystem/network/model imports (NFR-001, SC-004). packages/core/test/guardrail.no-network.test.ts

Implementation

Owner-aware allowed-zone in verdictFor — add currentProject? to VerdictInput; for a resource-scoped decision, the owner gets the existing path rule against allowed-in and a non-owner (incl. absent/unqualified) flags any detected touch, at the decision's declared posture. Detection reuses the existing rules (FR-003, FR-004, FR-006, FR-007, D-003). packages/core/src/guardrail/verdict.ts
Thread identity through the kernel command — pass currentProject from verdictCommand into verdictFor; the kernel reads no config itself (NFR-001, D-004). packages/core/src/commands/verdict.ts
Resolve identity at the CLI edge — the verdict command resolves the current project via resolveProjectConfig (as --explain already does) and passes it in (NFR-001, D-004). packages/cli/src/commands/verdict.ts
Exercise end-to-end — spawn the built binary with a resource-scoped decision and a non-owner fixture identity; assert the touch is flagged as cross-repo-not-owner. Entry point: spectastic verdict. packages/cli/test/verdict.resource.integration.test.ts

Closes FR-003, FR-004, FR-006, FR-007, NFR-001, SC-001, SC-002, SC-004.
