19 tasks across four phases. Small, and independent of 070–076 — it extends 069's element directly, so it can be drained at any time. There is no Foundational phase. 1 · Execution strategy

US1 — the producer is asked — plus US2's recording is the whole feature. US3's replay framing is the part that makes the answer meaningful rather than reflexive, so it is worth taking together.

Setup → US1 → US2 → US3 → Polish. Recommended. US1 and US3 both edit the same interview block, so sequencing avoids a collision.

Not worth splitting — two attributes, one prompt, one CSS line.

3 · Phase 3a — US1 · Changing a payload is a conscious decision

Tests (write & fail first)

Write the failing gating test — assert the questions are described as firing only on a change to an event-driven declared contract, and that a design changing no published payload is asked nothing, per FR-004 and SC-001. packages/cli/test/design.compatibility-prompt.test.ts

Add the gating rule — fire only when an event-driven declaration's contract is changing, per D-003. commands/spectastic.design.md

Closes FR-001, FR-004, NFR-002; contributes to SC-001.
