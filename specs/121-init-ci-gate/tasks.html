Init CI gate

Ordered, parallelizable work. Tests precede implementation. Drive through with /spectastic.implement — one task per invocation.

Status Accepted Spec 121-init-ci-gate Design design Branch main Created 16 Sep 2026 Read time

31 tasks across five phases. Setup → Foundational → User stories (US1 · US3 · US2 · US4, in priority order) → Polish. Tasks marked [P] can run in parallel — different files, no dependency. Tests for a story MUST be written and failing before its implementation tasks start.

1 · Execution strategy

Foundational, then US1 end-to-end (GitHub, all three steps) — the smallest demoable slice. Ship. US3's drift check and US2's failure-path proof follow since both are P1; US4's GitLab parity and Polish close the spec.

Setup → Foundational → US1 → US3 → US2 → US4 → Polish, in priority order. Each story closes its conformance before the next opens.

US1 and US3 depend only on Foundational and can run concurrently — the installer and the drift check touch disjoint files. US2 reuses US1's scratch project; US4 extends both US1's installer and US3's drift scan, so it starts last.
