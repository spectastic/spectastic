1 · Execution strategy

Setup → Foundational → US1 → US2 → US3 → Polish. Each story closes its conformance before the next opens. US1 (the order) and US2 (cycle hard-error) are both P1/must; US3 (elevation + WSJF) is P2/should — so the order also tracks priority. The natural path for solo foundation work.

Implement US1 end-to-end and demo the order, then add US2's cycle guard and US3's elevation. Viable because US1 is independently demoable (US1), but defers the must-tier cycle guard — only pick this if a real corpus with cycles isn't in play yet.

After Foundational, US2 (cycle detection) and US3 (elevation/WSJF) both extend topo.ts / order.render.ts, so they share seams with US1 — limited true parallelism. Coordinate at those files via the plan, not Slack.
