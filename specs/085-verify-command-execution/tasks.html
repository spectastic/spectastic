Running what was captured

Status Accepted Spec 085-verify-command-execution Design design.html Created 02 Aug 2026 Strategy Refusals first — the guards ship and are proven before anything can spawn a process. Read time

Eleven tasks. The order is deliberate: US2's refusals are built and tested before US1's executor exists, so there is never a commit in which this repository can run a command it should have refused.

Phase 1 · US2 — refuse anything foreign (first, on purpose)

Write the refusal tests before the guards — no opt-in, a dependency-directory path, and a path outside the project root, each a distinct refusal with no runner injected at all. packages/core/test/execcheck.test.ts
Build the consent guard — read the invoking project's config; absent the key, refuse and explain. packages/core/src/execcheck/guard.ts
Build the location guard, non-waivable — refuse anything outside the project root or inside a dependency directory, with no configuration able to permit it. packages/core/src/execcheck/guard.ts
Pin that guards cannot spawn — the guards take no runner port, so a test can prove 0 processes structurally rather than by watching for side effects. packages/core/test/execcheck.test.ts
 Closes FR-001, FR-002 and NFR-001; evidences SC-002.

Phase 2 · US1 — catch a command that stopped working

Write the outcome tests — passed, failed, timed out, skipped and absent, each distinct, against an injected runner. packages/core/test/execcheck.test.ts
Select the executable fields — build, entry point and tests only; never demo. packages/core/src/execcheck/select.ts
Execute under a limit through an injected port — capture output, terminate on timeout, and report the two apart. packages/core/src/execcheck/run.ts
Prove a broken command fails where structural checks pass — the whole point of the feature, per SC-001. packages/core/test/execcheck.test.ts
 Closes FR-003, FR-005 and FR-006; evidences SC-001.

Phase 3 · US3 — leave the prose alone

Skip an address-shaped entry point — a URL is legitimate per 083 and must be reported skipped, never attempted and never failed. packages/core/src/execcheck/select.ts
Skip a suggested block and pass an empty one — a capture that never claimed to work is not a failure, and neither is a spec with nothing to run. packages/core/src/execcheck/select.ts
Expose it as a thin CLI surface and run it live — register, delegate, and exercise it against this repository's own specs with the opt-in enabled. packages/cli/src/commands/verify-exec.ts
 Closes FR-004, FR-007, FR-008 and NFR-002; evidences SC-003.
