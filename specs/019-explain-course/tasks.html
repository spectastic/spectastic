1 · Execution strategy

Recommended. Drive US1 end-to-end — a target produces a grounded, verified course.html with a self-markable ledger. Then add US2 (the quiz gate), and US3 (keyless verification) once the artifact is real — US3 needs only the existing AIProvider seam, not US2's template work, so it can also land in parallel with US2 if staffed separately.

Setup → Foundational → US1 → US2 → US3 → Polish. Each story closes its conformance before the next opens.

After Foundational, one person on the kernel/CLI (US1) and one on the template + gate (US2's T-210) — they meet at templates/course.html, so coordinate there. US3 touches neither and can run as a third, independent stream once Foundational lands.
