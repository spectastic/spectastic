The exercise command

Fourteen tasks. Foundation collapses the duplicated renderer before anything is added to it; US1 threads the field through type, renderer and stylesheet; US2 proves the loud gap and the preservation path; US3 backfills the estate and extends the capture prompt. The backfill landed smaller and more conservative than planned — see the change log.

Phase 1 · Foundation

Nothing here is part of the feature. It is what makes the feature a one-line change instead of a two-line change in two files that must not disagree (D-001).

Extract the run-block renderer to its own kernel module — move renderRunBlock verbatim, exporting it unchanged. packages/core/src/runblock.ts
Point both verbs at the shared renderer — verify.ts re-exports it; renderExploreRunBlock becomes a delegating one-liner so no caller or test changes. packages/core/src/commands/verify.ts
Prove the unification changed no output — run the existing verify and explore suites before and after; both must pass untouched. packages/core/test/

Phase 2 · US1 — reach the feature from one line

Tests first, and failing, before any implementation task in this phase starts.

Write the round-trip test — a capture carrying an exercise entry point renders it verbatim inside its own element, in the position D-002 fixes. packages/core/test/verify.test.ts
Write the inertness test — a captured URL is escaped text and produces no anchor and no executable attribute, per NFR-002. packages/core/test/verify.test.ts
Add the field to the captured run type — one optional string, documented as the entry point rather than as a command so the address case reads as intended. packages/core/src/types.ts
Render the exercise row — emit the element between toggle and tests, empty when uncaptured. packages/core/src/runblock.ts
Style the row and its empty state — add the element to the layout, label and :empty selector lists so it inherits neither by accident. assets/spec.css
Measure the label column in a browser — resolve the design's open spike: confirm the uppercase label fits 5.5rem, and widen the column if it does not. tests/verify.view.spec.ts
 Closes FR-001, FR-002, FR-003 and NFR-002; evidences SC-001.

Phase 3 · US2 — see that nothing was recorded

Write the preservation test — a links-only regeneration keeps an exercise entry point already present, per FR-005. packages/core/test/verify.test.ts
 Closes FR-004 and FR-005.

Phase 4 · US3 — inherit the commands already written down

Confirm the corpus is unharmed — whole-corpus validate reports no new finding, satisfying NFR-001. specs/
 Closes FR-006, FR-007 and NFR-001; evidences SC-002 and SC-003.
