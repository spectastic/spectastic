Status Accepted Spec 074-contract-checked-tier Plan plan Branch main Created 01 Aug 2026 Read time

21 tasks across five phases. This slice raises a floor, so the below-verified regression set comes first — at most 0 lean or standard projects may gain a gap. Like 073 it amends 042 by proposal before touching code. The tier gate is built before any signal, so a below-verified project short-circuits and cannot change verdict even by accident.

1 · Execution strategy

US1 is the rung itself and is demoable alone. US3's capability carve-out should not lag — without it, an AsyncAPI project is held to a promise the ecosystem's tooling cannot keep.

Amendment → Setup → Foundational → US1 → US2 → US3 → Polish. Recommended. All three stories touch the same evaluation path, so sequencing avoids collisions.

Poor fit — one category, one evaluation path. The profile copy (T-900) is the only genuinely detachable piece.
