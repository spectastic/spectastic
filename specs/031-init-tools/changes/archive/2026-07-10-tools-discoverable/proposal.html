Add FR-011 — the guarantee layer is discoverable at init

A guarantee nobody knows the flag for is a guarantee nobody gets.

Status Applied Change ID 2026-07-10-tools-discoverable Spec 031-init-tools Source triage 031/T-001 (dogfooding on spec-tictactoe-2) Author Brian Corbin · @briancorbinxyz Created 10 Jul 2026 Targets 1 added (FR-011, should) Read time

On a dogfooded project, auto-commits never happened because init --tools was never set — and, unlike the 041 profile prompt, nothing surfaced it during interactive init. This change adds FR-011: interactive init offers the guarantee layer, and a non-interactive run prints a one-line tip, so a user never silently ends up with no gate simply because they didn't know the flag. A single additive SHOULD requirement.

Add FR-011 — the guarantee layer is discoverable at init

Applied

1 · Intent

031 shipped --tools as a flag mode with no interactive surface. 041 later added an interactive profile prompt; tools never got the equivalent. The asymmetry is the defect (T-001): profiles are discoverable, tools are not, so a user who didn't pass the flag gets no pre-commit gate and no auto-commit — and no signal that it exists.

2 · Scope

In scope

  • ADD FR-011 (should): interactive init offers to install the guarantee layer; non-interactive prints a tip.
  • Append a changelog entry citing T-001.

Out of scope

  • Auto-installing the guarantee layer by default — it stays opt-in; the fix is discoverability, not a changed default.

3 · Approach

One additive SHOULD delta. Implemented by reusing the 041 interactive-prompt seam: a confirmTools prompt in a TTY runs the existing runTools installer; a non-TTY run prints a tip. Adversarial pass did not auto-fire (should-tier, single topic); no risks recorded.

4 · Deltas

What's added: a should-tier requirement making the guarantee layer discoverable at init.

The guarantee layer SHOULD be discoverable at init, not flag-only: an interactive (TTY) init SHOULD offer to install it, and a non-interactive run SHOULD print a one-line tip that it exists — so a user never silently ends up with no gate (and no auto-commit) simply because they didn't know the flag.
