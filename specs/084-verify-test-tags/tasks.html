Tasks · 084-verify-test-tags

A durable test selector

Status Accepted Spec 084-verify-test-tags Design design.html Created 02 Aug 2026 Strategy MVP-first — US1 is the reader; US2 derives from it; US3 is the safety property that lets it ship into an untagged estate. Read time

Twelve tasks. Foundation fixes the grammar; US1 builds and proves the reader; US2 resolves tags against the estate and derives the citation; US3 pins the no-tags and partial-tags behaviour and pilots the convention on the browser suite.

Phase 1 · Foundation

Define the tag grammar — parse and format @NNN and @NNN:ID, rejecting a bare unqualified id since requirement ids are unique only within their own spec. packages/core/src/testtags/grammar.ts
Cover the grammar's edges first — qualified and unqualified forms, a tag inside surrounding prose, and the rejection of a bare id. packages/core/test/testtags.test.ts

Phase 2 · US1 — select without naming files

Write the reader's tests against real files — a fixture tree with tagged and untagged tests, asserting deterministic ordering per NFR-001. packages/core/test/testtags.test.ts
Build the reader — walk test files and extract tags from title string literals and Playwright tag arrays, executing nothing. packages/core/src/testtags/read.ts
Prove the selector survives what a path list does not — a test added under an existing tag is picked up with no change to the recorded command, per SC-001. packages/core/test/testtags.test.ts
 Closes FR-001 and FR-002; evidences SC-001.

Phase 3 · US2 — derive rather than assert

Write the resolver's tests — a tag naming a missing spec, a tag naming an id its spec does not define, and a requirement with no tagged test, each a distinct outcome. packages/core/test/testtags.test.ts
Resolve tags against the estate — map each tag to its spec and id, reporting an unresolvable tag as a finding rather than dropping it. packages/core/src/testtags/resolve.ts
Derive the citation and its coverage figure — return the id set together with tagged and total counts, so a partial result cannot present as complete. packages/core/src/testtags/resolve.ts
Expose it as a thin CLI subcommand — register and delegate; no logic in the command module. packages/cli/src/commands/testtags.ts
 Closes FR-003, FR-004 and FR-005.

Phase 4 · US3 — adopt without a flag day

Pin the no-tags behaviour — an untagged tree yields an empty result and a successful exit, never an error, per FR-006. packages/core/test/testtags.test.ts
Pin the partial-result labelling — a tree where some tests are tagged reports its coverage figure alongside the derived set. packages/core/test/testtags.test.ts
Pilot the convention on the browser suite — tag the verify tests, run the derived citation against the hand-written one, and record every difference. tests/verify.view.spec.ts
 Closes FR-006, FR-007, FR-008 and NFR-002; evidences SC-002 and SC-003.
