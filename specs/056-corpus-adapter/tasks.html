3 · Phase 2 — Foundational

Shared derivation logic both input modes call identically.

Implement the per-doc derive helper — a sha256:<hex> content hash (Node crypto) computed from the source bytes; every other provenance field the source doesn't supply emits the literal TODO, never a guess (D-004). packages/core/src/knowledge/adapt.ts
Implement sequential KB-NNN id allocation — scan the target pack for the highest existing id, assign max+1, max+2… to new files in sorted-filename order (D-003). packages/core/src/knowledge/adapt.ts

4 · Phase 3a — US1 · An existing markdown folder becomes citable

Tests (write & fail first)

Test folder-mode N → N + validate-accepts — adapting a temp directory of N raw .md files yields N valid KB-NNN-fronted documents and an N-row index.md that a folded spectastic validate pass accepts with zero errors. packages/core/test/knowledge.adapt.test.ts

Implementation

Implement folder-mode routing — walk the target directory (direct node:fs, mirroring loadCorpus's own convention, not the AI-verb ctx.fs shape), filter to .md files, skip any already carrying a valid KB-NNN id (idempotency), and derive + allocate the rest. packages/core/src/knowledge/adapt.ts
Write the derived frontmatter + merged index.md — emit each document's ----fenced frontmatter back into place and write knowledge/<pack>/index.md's 5-column table. packages/core/src/knowledge/adapt.ts

Closes FR-001 (folder leg), SC-001.

5 · Phase 3b — US2 · An llms.txt as the index source

Tests (write & fail first)

Test llms.txt entries correspond to index rows — a temp llms.txt with M linked markdown files yields an M-row index whose rows trace to those entries, and the linked files gain frontmatter. packages/core/test/knowledge.adapt.test.ts

Implementation

Implement llms.txt index-seed mode — parse the markdown-link entries, resolve each linked file relative to the llms.txt's own directory, seed the index rows from the entries, and derive + allocate frontmatter for the files they link (reusing T-010/T-011). packages/core/src/knowledge/adapt.ts

Closes FR-001 (llms.txt leg).

6 · Phase 3c — US3 · Nothing is fabricated

Tests (write & fail first)

Test an underivable field emits TODO, never a guess — a source file with no discernible license/origin yields license: TODO / origin: TODO exactly, and never any other placeholder value. packages/core/test/knowledge.adapt.test.ts
Test idempotent re-run — running the adapter twice on the same source produces no duplicate ids or index rows, and a provenance field a human hand-corrected between runs survives the second run untouched. packages/core/test/knowledge.adapt.test.ts

Implementation

Implement the idempotency guard — a file with hasFrontmatter && id (051's parseCorpusDocument) is skipped whole; the index merge is by id, keyed so an existing non-empty cell always wins; no non-TODO provenance value is ever rewritten to TODO (D-005). packages/core/src/knowledge/adapt.ts
Wire the corpus adapt CLI command's body — resolve the target pack name (default: the source folder's basename), call adaptCorpus, print a count summary, and end with the silent-loss caveat prompting a spot-check of the emitted documents (FR-003). packages/cli/src/commands/corpus.ts
Register the corpus command group packages/cli/src/index.ts

Closes FR-002, FR-003, NFR-001, SC-002, SC-003.

7 · Phase 4 — Polish

Document the adapt tier in the README — the adopt/adapt/bridge framing, the corpus adapt command, and the documented (never depended-on) conversion recipe: Docling as the default, MarkItDown for the fast path, Marker where fidelity justifies a GPU (FR-004's no-converter boundary). README.md
Run the full safety-net verification — the whole vitest + tsc suite, plus a corpus-wide spectastic validate, confirming zero new findings across every existing spec. (repo-wide)
