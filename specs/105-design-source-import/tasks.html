1 · Execution strategy

Implement US1 end-to-end. Ship. Iterate to US2 and US3 only after US1 is verified.

Setup → Foundational → US1 → US2 → US3 → Polish. Each story closes its conformance before the next opens.

One team on each user story after Foundational. Coordinate at shared seams (data model, API contracts) via the spec, not Slack.

4 · Phase 3a — US1 · An export becomes committed material

Write the disappearance test red — after an import, delete the source folder and assert the project still validates. This is the property, not a nice-to-have. packages/core/test/visual-import.test.ts
Read a local export through the seam — no network, no credential, one code path for every source. packages/core/src/providers/local-source-fetcher.ts
Register the import subcommand — registrar only: parse, call core, print the ledger, exit. packages/cli/src/commands/visual.ts

5 · Phase 3b — US2 · Re-importing does not destroy work

Write the re-import tests red — an unchanged source writes no bytes; a changed one replaces; material the source no longer has is reported and never deleted. packages/core/test/visual-import.test.ts
Make re-import non-destructive — an element missing from an export is as likely to be an export setting as a deletion, and reporting is recoverable where deleting is not. packages/core/src/visual/import.ts
Protect hand edits, except where the export owns the field — both halves, because the corpus was wrong in one direction and protecting a field with a real source of truth silently desynced the copy. packages/core/src/visual/import.ts
Refuse a re-import that would change identity — naming both, since a quiet fork is worse than a loud refusal. packages/core/src/visual/import.ts

6 · Phase 3c — US3 · An inferred value never passes for a declared one

Write the derivation tests red — candidates come back marked inferred; a declared value always wins; the stub provider drives it with no credential. packages/core/test/visual-import.test.ts
Derive token candidates from an emitted stylesheet — through the existing text-only AI port, so no multimodal widening is needed. packages/core/src/visual/derive-tokens.ts
Present candidates for confirmation rather than committing them — what keeps declaration-over-inference true in practice and not only in the file. packages/core/src/visual/import.ts

7 · Phase 4 — Polish

Assert atomicity — an interrupted import leaves no partially written file. packages/core/test/visual-import.test.ts
Report an unhandled annotation category rather than dropping it — the category map exists to name the ones with nowhere to go, and dropping one silently would waste the mechanism. packages/core/src/visual/import.ts
Confirm no default-tier test needs a credential — the project's standing rule for anything model-coupled. packages/core/test/visual-import.test.ts
