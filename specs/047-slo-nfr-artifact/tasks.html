1 · Execution strategy

Setup → Foundational → US1 → US2 → US3 → Polish. US1 (the element + shape rules) is the load-bearing slice — US2 and US3 both read the same <spec-slo target> shape US1 defines. Matches the plan's Low risk-tolerance call (D-005): every locus copies a shipped pattern, so sequencing by dependency rather than parallelizing across stories keeps the copy-verify loop tight.

Ship US1 alone first (the representation — SC-001) and stop. US2/US3 (the quantified-NFR gate) land as a second pass once the element has seen real use.

Not recommended here — US2's quantified scan reads the same target-resolution logic US1's shape rule defines, and US3 extends US2's scan directly. The dependency chain is real, not just conventional.
