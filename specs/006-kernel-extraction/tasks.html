Scaffold the packages/core/ package skeleton + workspace integration. All [P] — different files.

Create packages/core/package.json with name @spectastic/core, version matching packages/cli's current (synced policy per D-001), "publishConfig": {"access": "public"}, dependency on @spectastic/schema: "workspace:*", keywords + repository fields per the established pattern. packages/core/package.json
Create packages/core/tsconfig.json extending the same base shape as packages/cli/tsconfig.json; moduleResolution: "NodeNext"; emit .d.ts. packages/core/tsconfig.json
Create packages/core/tsup.config.ts with multi-entry array per D-002: ['src/index.ts', 'src/commands/validate.ts', 'src/providers/node-fs.ts']; emit ESM + .d.ts per entry. packages/core/tsup.config.ts

3 · Phase 2 — Foundational

Shared types + default IO impl that everything else depends on. T-010 first; T-011 + T-012 depend on it.

Create packages/core/src/types.ts declaring KernelContext (per D-003), FileSystem (per D-005 — readFile / writeFile / readdir / stat), AIProvider (per D-004 — chat + ask<T> + subagent), Question, ChatOpts, SubagentOpts, SubagentResult, and the per-verb ValidateInput / ValidateResult shapes. Re-export Finding from @spectastic/schema. packages/core/src/types.ts
Create packages/core/src/index.ts as the main entry — types-only re-exports from ./types.js. MUST NOT import any verb command module (per FR-002); the lazy-loading discipline depends on this file staying free of command code. packages/core/src/index.ts
Create packages/core/src/providers/node-fs.ts exporting nodeFs: FileSystem — a thin wrapper around node:fs/promises's readFile / writeFile / readdir / stat. Used as ctx.fs default when caller doesn't pass one. Lazy-loaded; not imported by index.ts. packages/core/src/providers/node-fs.ts

4 · Phase 3a — US1 · CLI consumer sees no change P1

The smallest demoable: extract validate end-to-end with byte-identical CLI behaviour.

Tests (write & fail first)

Write packages/core/test/validate.test.ts with an in-memory ctx.fs stub serving three fixtures: (a) a clean spec-html, (b) one with a deliberate finding, (c) a non-existent path. Assert ValidateResult shape (findings, exitCode, filesValidated) and exit-code mapping (0 / 1 / 2) for each. Import via '@spectastic/core/commands/validate' subpath (not relative path) — proves SC-003. Tests fail initially because T-110 hasn't landed. packages/core/test/validate.test.ts

Implementation

Create packages/core/src/commands/validate.ts implementing validateCommand(input: ValidateInput, ctx: KernelContext): Promise<ValidateResult>. Reads each input.files path via ctx.fs.readFile, calls @spectastic/schema's validateMany, structures the result. No glob expansion (per D-006). Docblock notes "no slash-command counterpart; CLI subcommand is the primary surface" per FR-008. packages/core/src/commands/validate.ts
Refactor packages/cli/src/commands/validate.ts to import validateCommand from @spectastic/core/commands/validate instead of calling @spectastic/schema directly. CLI keeps glob expansion, output formatters (human/json/sarif), and process.exit(result.exitCode). No behavioural change (per D-007 + FR-006). packages/cli/src/commands/validate.ts
Run pnpm -r build end-to-end. Confirm all three packages build cleanly; types resolve across the workspace dependency edges; CLI's typecheck consumes @spectastic/core's emitted .d.ts. packages/{core,cli,schema}/dist/
Run pnpm test and confirm: (a) T-100 kernel unit tests pass; (b) existing packages/cli/test/cli.test.ts integration tests stay green (proves CLI shim wiring); (c) packages/schema/test/** still green; (d) total count is 64 (existing) + N (new kernel tests). (test run)
Run pnpm bench and confirm all four scenarios within budget. init-help-cold-start p50 stays within ±20% of today's 52 ms CI baseline (the lazy-loading regression guard per NFR-001); validate-full-project p50 within ±20% of 295 ms CI baseline (per NFR-002). (bench run)
Manual byte-identity check (SC-004): capture node packages/cli/dist/index.js validate "specs/**/*.html" "examples/**/*.html" inbox.html principles.html stdout before and after the extraction. Diff. Result MUST be byte-identical modulo trivial whitespace. (manual smoke; output comparison)
