Ordered, parallelizable work. Drive through with /spectastic.implement — one task per invocation.

Status Accepted Spec 004-npm-publish-workflow Plan plan Branch 004-npm-publish-workflow Created 15 Jun 2026 Read time

22 tasks across five phases. Setup wires Dependabot + the one-time npm-org bootstrap; Foundational scaffolds the workflow file and the shared install + gate steps; US1 wires the publish path; US2 adds the dry-run job + README; US3 is a single manual provenance verification (config is covered in Foundational); Polish drives the first real release and verifies SC-001..SC-003 against npm and a clean environment. Tasks marked [P] can run in parallel.

1 · Execution strategy

Skeleton workflow → publish step → first real publish at 0.1.0-pre.3 — minimum to make npm i -g work for an outsider. Layer dry-run, README, Dependabot, and verification work after the first release lands.

Setup → Foundational → US1 → US2 → US3 → Polish. Each story closes its conformance before the next opens. Recommended for solo work; lowest coordination cost. Polish gates on the first real publish having landed.

One contributor on the workflow file (Foundational + US1); one on the README docs (US2); they meet at the dry-run job. Useful only if you have two people; for solo work, Incremental is cleaner.
