14 tasks across five phases. Setup → Foundational → User stories (US1·US2·US3) → Polish. Tasks marked [P] can run in parallel — different files, no dependency. The one code stream (US3, packaging) is test-first with vitest; the coach itself (US1·US2) is prose with no artifact, so it is verified by a manual smoke checklist authored before the procedure — per D-001.

1 · Execution strategy

Recommended for this solo slice. Implement US1 (the grounded coach) end-to-end and smoke it. Add US2 (band depth) and US3 (opt-in install) only after US1 is verified. US3 is independent and can be picked up whenever convenient.

Setup → Foundational → US1 → US2 → US3 → Polish. Each story closes its conformance before the next opens.

The coach (US1+US2, one command file) and the packaging seam (US3, the CLI bundler) are almost independent after Foundational — two people could take one each. Coordinate only on commands.json, which both reference.
