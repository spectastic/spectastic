US2 (slash-command MAY-Bash note) is a one-line markdown touch; tag it off when convenient. Polish ships the version bump + tag + publish. Pick this one for solo work.

Setup → Foundational → US1 → US2 → Polish, each phase closing its conformance before the next opens. Slightly more ceremony than MVP-first; cleaner if multiple contributors are involved.

3 · Phase 2 — Foundational

Per-verb types + the template loader helper. T-010 first; T-011 depends on the types it adds.

Extend packages/core/src/types.ts with PrinciplesInput (projectName?: string, principlesCount?: number, outputPath?: string) per D-003, PrinciplesResult (html: string, principlesCount: number) per spec §4, and the typed PrinciplesExistsError class per D-002. packages/core/src/types.ts
Create packages/core/src/helpers/principles-template.ts — a small template loader that resolves join(ctx.cwd, 'templates/principles.html'), reads it via ctx.fs.readFile, throws TemplateNotFoundError on miss, and applies the ../assets/ → ./assets/ rewrite per D-004. Disk-read per the matrix in plan §4. packages/core/src/helpers/principles-template.ts

4 · Phase 3a — US1 · Maintainer authors fresh principles via the CLI P1

The smallest demoable: spectastic principles in a clean directory produces a valid principles.html, kernel-first.

Tests (write & fail first)

Write packages/core/test/principles.test.ts — unit tests importing principlesCommand via the subpath '@spectastic/core/commands/principles'. In-memory ctx.fs stub serves the template; stub ctx.ai.chat() returns canned answers. Covers (a) fresh-generate happy path (asserts html contains rendered project name + 3–5 P-N blocks, principlesCount matches per SC-001) and (b) refuse-if-exists — ctx.fs.stat returns "file exists" → rejects with PrinciplesExistsError before any AI call per D-002. Tests fail until T-110 lands. packages/core/test/principles.test.ts

Implementation

Create packages/core/src/commands/principles.ts implementing async function principlesCommand(input: PrinciplesInput, ctx: KernelContext): Promise<PrinciplesResult>. Reads template via the T-011 helper (ctx.fs), stats output path and rejects with PrinciplesExistsError if present per D-002, interviews missing input fields via ctx.ai.chat() per D-003, fills placeholders, returns { html, principlesCount } per D-001. Docblock links to commands/spectastic.principles.md as canonical procedure per FR-007. packages/core/src/commands/principles.ts
Create packages/cli/src/commands/principles.ts — the spectastic principles subcommand. Imports principlesCommand from @spectastic/core/commands/principles, constructs ClaudeProvider (from 007) + nodeFs + KernelContext, calls kernel, writes html to ./principles.html, exits 0. PrinciplesExistsError → exit 1 + message "principles.html already exists; use /spectastic.propose to amend"; usage error → exit 2 per D-006 and FR-003. Register the subcommand in the CLI dispatcher. packages/cli/src/commands/principles.ts
Write packages/cli/test/principles.integration.test.ts — integration test that spawns spectastic principles via process in a temp dir with a stub-provider injection, feeds canned answers, asserts the written principles.html file matches the kernel's expected structural output per FR-005 + SC-002. Byte-identity interpreted structurally per plan §7. packages/cli/test/principles.integration.test.ts
Run pnpm -r build end-to-end. Confirm core + cli build cleanly; the new subpath emits dist/commands/principles.{js,d.ts}; CLI's typecheck consumes the kernel function's type. packages/{core,cli}/dist/
Run pnpm test and confirm: (a) T-100 kernel unit tests pass; (b) T-112 CLI integration test passes; (c) existing 006-era tests stay green (no regression in packages/cli/test/cli.test.ts, packages/core/test/validate.test.ts, schema suite). (test run)
Run pnpm bench and confirm all scenarios within budget per SC-003. init-help-cold-start p50 stays within ±20% of the post-007 baseline — proof the new principles subcommand did not land on the cold-start path via eager imports per NFR-001. (bench run)
Manual smoke: in an empty temp dir, run node packages/cli/dist/index.js principles, feed real answers via stdin, confirm a valid principles.html is produced (placeholders all filled, 3–5 P-N blocks emitted, asset paths rewritten to ./assets/). Re-run in the same dir, confirm exit 1 + "already exists" message per FR-004. (manual smoke)

Closes FR-001, FR-002, FR-003, FR-004, FR-005, FR-007, NFR-001, SC-001, SC-002, SC-003.
