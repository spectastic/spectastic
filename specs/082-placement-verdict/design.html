5 · Approach

The whole design turns on one requirement: structural evidence must be able to outrank resemblance. That is the survey's central finding made mechanical, and it is why evidence is typed rather than summed into an opaque number. Each candidate accumulates findings of four named classes — structural (a dependency edge from 079), declared (a boundary map from 081 or an explicit declaration), domain (lexical closeness to a candidate's specs and corpus), and prior-art (this project has specced something like it before) — and each finding carries its own weight and source. A reader disagreeing with a verdict can disagree with a specific piece of evidence rather than with the tool.

The refinement pass needs its own honesty. The default path is pure: same inputs, same ranking, no clock and no iteration-order dependence. An opt-in model pass may re-order, and that is genuinely useful for judging closeness a token count cannot see — but a verdict a reviewer cannot reproduce is one they cannot argue with. So the verdict records which mode produced it. That is not decoration: it is the difference between "re-run this and check" and "take my word for it", and leaving it implicit would quietly erode the property NFR-003 exists to protect.

Both refusals fall out of the same accumulation. If no candidate reaches the confidence floor, the answer is no confident owner with the reasons attached — never the least-bad candidate, because forced choice over a ranked list always returns something and what it returns is the unit whose vocabulary the requirement borrowed. If nothing fits at all, the engine may propose a new unit, and creates nothing.

6 · Alternatives considered

OptionReproducibleJudgement qualityHonest to NFR-003CostTotal
A · Fully deterministic 525517
B · Deterministic core, opt-in refinement, mode recorded 445417
C · Model-backed throughout 151411

A and B tie, and the tie is the honest result. Both are fully honest to NFR-003 — B complies on the default path and labels the exception, which is not a lesser kind of honesty than never offering one. A is cheaper and always reproducible; B judges closeness better where a token count is too blunt. The tiebreak is a judgement rather than a score: a purely lexical ceiling on resemblance is a real limitation, and the reproducibility cost is bounded because the default path stays pure and the mode is visible on every verdict. C loses outright, and would need NFR-003 amended rather than merely interpreted.

7 · Decisions

D-001 · A deterministic core with an opt-in refinement, and the verdict records which produced it

Status
Accepted
Context
NFR-003 requires the same inputs to yield the same ranking, and names clock, filesystem ordering and iteration order specifically. Read literally, an opt-in pass outside the default path does not violate it. But a verdict a reviewer cannot reproduce is one they cannot argue with, and that property erodes silently if nothing marks which kind they are holding.
Decision
The default path is pure and reproducible. A model refinement is opt-in and may re-order. Every verdict records its mode, so "re-run this and check" is distinguishable from "take my word for it" without reading the invocation.
Consequences
+ The default stays checkable, which is what makes a suggestion arguable. + Closeness judgements a token count cannot make become available where they are wanted. + The reproducibility question is answered on the artifact rather than left to the reader. − Two paths mean two behaviours to test and explain. − A refined verdict is genuinely not reproducible; the label makes that visible but does not remove it.

D-002 · Domain resemblance is lexical overlap, deliberately weak

Status
Accepted
Context
The corpus resists a vector store by standing decision, and its read path is metadata query plus body grep. FR-003 requires structural evidence to be able to outrank resemblance, and FR-009 forbids domain evidence alone from reaching the unhedged band.
Decision
Normalised token overlap between the requirement and each candidate's specs and corpus documents. No embeddings, no index.
Consequences
+ Deterministic and cheap, with no new dependency. + A weak signal is the correct strength for the one the survey says must be outrankable — a sharper one would make the opening failure more confident, not less. − It will miss a genuinely related requirement phrased in different words; that is what the opt-in refinement exists for. − Common-word noise needs handling, or every candidate scores alike.

D-003 · Weights are uncalibrated defaults in core, overridable in config

Status
Accepted
Context
NFR-001 requires weights to be configurable and declared uncalibrated, with at most 0 presented as measured. change-risk/score.ts already does exactly this and says so in its own comment.
Decision
Named constants in core carrying an explicit "v1 default, not measured" statement, overridable through spectastic.json — cloning the change-risk shape rather than inventing a second one.
Consequences
+ One precedent, already proven in this estate. + A tuned-looking number cannot be mistaken for evidence in itself. − Configurable weights mean two projects can reach different verdicts on the same estate; acceptable, since the weights are admittedly a guess.

D-004 · Extend the units module's arrangement; scoring stays pure

Status
Accepted
Context
REQ-LIFECYCLE-008 asks the architecture question be answered deliberately. 079 established ports-and-adapters for this module and 081 extended it; this slice consumes both.
Decision
No new pattern. Evidence gathering sits behind the existing port; ranking and the verdict are pure functions over gathered evidence, testable with plain objects.
Consequences
+ The ranking rules — including FR-003's outranking property — are unit-testable without fixture directories. + One arrangement across the whole units family. − Another decision whose content is "keep going", written because the requirement asks the question be answered rather than skipped.

9 · Risks & mitigations

RiskLikelihoodImpactMitigation
Resemblance outranks structure and reproduces the exact failure this slice exists to prevent MediumHigh The headline test: a requirement in consumer vocabulary with a structural edge to the producer must rank the producer first. FR-009 additionally caps domain-only evidence below the unhedged band.
Lexical overlap scores every candidate alike, so ranking is noise MediumMedium Normalise for length and drop very common tokens. Asserted by a test where two candidates differ only in topic.
Abstention is so frequent the engine stops being consulted UnknownMedium Named in the spec's own consequences and genuinely unmeasurable here — it needs real use. Recorded rather than mitigated, and it is why calibration is deferred rather than guessed at.
A refined verdict is mistaken for a reproducible one LowMedium The mode is on the verdict (D-001) and asserted by a test, so the distinction cannot be lost in the output.
