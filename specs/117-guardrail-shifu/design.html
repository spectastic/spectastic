Teaching follow-up (shifu)

How we will build it.

Status Accepted Spec 117-guardrail-shifu Owner Brian Corbin · @briancorbinxyz Branch main Created 13 Sep 2026 Read time

A pure shifuQuestions(verdict) that templates one Socratic question per violation from the decision reason + source→target, surfaced by an opt-in verdict --teach. No LLM, off the enforcement path. Biggest risk: a template that reads as a fix rather than a question — mitigated by a test asserting it ends in "?" and carries no imperative verb.

6 · Approach

Add shifuQuestions(verdict) to the guardrail module: for each violation, template one question — "Decision <id> exists so that: <reason> — this change has <source> reaching <target>. What makes that necessary here rather than the path the decision intends?" — falling back to a reason-only form when source→target is absent. Add --teach to the verdict CLI, printing the questions after the verdict under an advisory header, leaving the exit code and persisted artifact untouched.

8 · Decisions

D-001 · A deterministic templated question, not an LLM

Context. 115's Violation carries reason + source→target (grounding row 1). Decision. Template one question per violation from those fields; no model. Consequences. + Deterministic, testable, needs no key; can't drift. − Fixed phrasing (no wording variety) — the deferred LLM variant if that ever matters.

D-002 · Surface via verdict --teach, output-only

Context. The verdict CLI already prints the verdict (verdict.ts). Decision. A --teach flag prints the questions after the verdict; the exit code and artifact are untouched. Consequences. + Off the enforcement path by construction. − One more flag to document.

D-003 · Test-first, low risk

Context. One pure composer + one flag. Decision. TDD; low risk. A "no imperative verb, ends in ?" test guards the never-a-fix property. Consequences. + Regression-guarded. − None material.

10 · Risks & mitigations

The template reads as a fix, not a question

Likelihood medium, impact medium. Mitigation: a test asserts each question ends in "?" and contains no imperative fix verb (add/change/replace/use).

--teach accidentally changes the verdict

Likelihood low, impact high. Mitigation: shifu reads a Verdict and returns strings; it never touches the verdict or exit code — an integration test asserts identical exit with and without --teach.
