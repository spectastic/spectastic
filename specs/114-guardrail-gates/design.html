3 · Data model & contracts

No external interface or contract — both scans are internal. They consume 113's GovernanceDecision[] (from loadDecisions) and the parsed design documents already in the validate run. The declared surface is the set of path-like tokens extracted from a design's #structure section; an acknowledgment is a reference to a decision id or coordinate anywhere in the design.

6 · Approach

Add two pure kernel functions and two thin CLI wrappers that fold into the existing validate run beside scanQuantifiedNfr. The plan-constraint reads every design's declared surface, matches 113's active decisions (authored elsewhere) against it with 113's glob matcher, and errors on any unacknowledged match — gated to standard+ by the marker. Coverage counts, over all active decisions, those carrying a rule versus those neither checked nor excused, warns on the gaps and on any past review-by, and reports the proportion.

validate run
  ├─ scanQuantifiedNfr        (existing)
  ├─ scanPlanConstraint  ──▶  planConstraintFindings(designs, decisions, {tier})   [error @ standard+]
  └─ scanDecisionCoverage ─▶  coverageFindings(decisions, {now})                    [warning, never blocks]
                                        ▲
                     loadDecisions(specs/*/design.html)  ── 113
   spectastic adrs --coverage ─▶ prints the proportion (the report surface)

8 · Decisions

D-001 · Both gates are folded CLI scans over the kernel, cloning scanQuantifiedNfr

Context. The gate must read the profile tier and all decisions (cross-file), which a per-file schema rule cannot (validate.ts:348). Decision. Kernel planConstraintFindings/coverageFindings + CLI scanPlanConstraint/scanDecisionCoverage, folded into the validate run. Consequences. + Reuses a proven, benched pattern; runs in the pre-commit gate. − Two more folded scans on the validate path (short-circuited below standard, so the cost lands only where active).

D-002 · The plan-constraint gates at standard and above

Context. The human decision raised the blocking floor to standard (quantified-NFR gates at verified+; validate.ts:433). Decision. A new isPlanConstraintGatedTier over {standard, verified, enterprise}, read from the marker; absent marker ⇒ no-op. Consequences. + A contradicted decision fails from standard up. − A lite/unmarked project gets no plan-constraint (fail-safe on the antecedent, like the enforce floor).

D-003 · The declared surface is the project-structure tree, matched by path-prefix overlap

Context. The spec interview chose to reuse the design's §Project-structure tree rather than add a required field; a spike over all 105 designs confirmed it is recoverable (grounding row 5): every design yields path tokens, but they are directory-coarse (packages/core/, scripts/). Decision. Extract the first path-ish token per tree line (comment stripped); a decision is in-scope when its scope glob and a declared token overlap — a declared path within the scope, or a declared ancestor of it — not on exact glob-match. Consequences. + No new authoring surface; works across the whole estate. + Overlap errs toward MORE acknowledgment, which is right for a happy-path nudge. − A coarse declared dir may prompt for a decision the author will not actually touch, and a path never written into the tree is invisible — both acceptable because the merge verdict in 115 checks the actual diff and is the guarantee this plan-time nudge is not (the honest P-8/T-009 line).

D-004 · Coverage warnings fold into validate; the proportion is an explicit report

Context. Coverage must not block (spec FR-005), but its warnings should surface in the normal gate. Decision. The unchecked-and-unexcused and past-review-by warnings are warning-severity findings in validate; the proportion metric is printed by spectastic adrs --coverage (extending 113's command, which already loads decisions). Consequences. + The gate carries the actionable warnings without blocking; the metric is a report you run. − The headline percentage is not in the default validate output.

D-005 · Test-first, low risk — inherited from the slice

Context. 112 and 113 were both authored test-first on this same pattern. Decision. TDD; low risk tolerance — a proven path, no experimental unknowns. Consequences. + Consistent, regression-guarded. − None material.

10 · Risks & mitigations

Declared-surface granularity mismatch (coarse dirs vs specific scopes)

Likelihood medium, impact low. Spike-confirmed the tree is recoverable across all 105 designs; matching by path-prefix overlap handles the coarse-dir case, erring toward more acknowledgment. A path never written into the tree stays invisible — bounded by 115's diff-level verdict, the real guarantee.

False-firing on the existing estate at standard+

Likelihood low, impact high. Mitigation: no existing decision carries scope metadata yet, so the constraint matches nothing on the current corpus; the whole-estate integration validate is the gate.
