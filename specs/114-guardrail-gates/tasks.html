Governance gates — plan constraint & coverage

Ordered, parallelizable work. Tests precede implementation.

Status Accepted Spec 114-guardrail-gates Design design Branch main Created 13 Sep 2026 Read time

Ten tasks across foundational → two stories → polish. US1 is the plan-stage constraint (error at standard+); US2 is the coverage report (warnings, never blocking). Tests are written and failing before each story's implementation.

1 · Execution strategy

Foundational (tier gate) → US1 plan-constraint (tests then code, folded into validate) → US2 coverage → polish (backward-compat + full suite). Each story closes its conformance before the next.

Ship US1 (the plan-constraint — the Priya-killer) end-to-end and verify it; add coverage after.

After the tier gate lands, one engineer on US1 (plan-constraint) and one on US2 (coverage) — different core files, no shared in-flight dependency.

2 · Phase 2 — Foundational

Add the plan-constraint tier gate — isPlanConstraintGatedTier over {standard, verified, enterprise}, mirroring isQuantifiedNfrGatedTier. packages/core/src/guardrail/gated-tiers.ts

3 · Phase 3a — US1 · The plan-stage constraint

Tests (write & fail first)

Plan-constraint unit tests — a design touching a governed path without acknowledgment fails; acknowledging clears it; a design's own decision never fires; below standard produces nothing (SC-001, SC-004). packages/core/test/guardrail.plan-constraint.test.ts
No-network assertion for the gates — both scans' transitive imports carry 0 model/network modules; 0 direct network calls (SC-003). packages/core/test/guardrail.gates.no-network.test.ts

Implementation

Declared-surface extractor + planConstraintFindings — extract path tokens from the project-structure tree, match active decisions (authored elsewhere) by path-prefix overlap, error on unacknowledged, exclude own decisions. packages/core/src/guardrail/plan-constraint.ts
Fold scanPlanConstraint into validate — read the marker, short-circuit below standard, call the kernel; beside scanQuantifiedNfr. packages/cli/src/commands/validate.ts
Exercise the constraint end-to-end — run spectastic validate on a fixture design whose tree touches a governed path at the standard profile; assert it fails naming the decision + path, and passes once acknowledged. Entry point: spectastic validate.

Closes FR-001, FR-002, FR-003, FR-004, FR-006, NFR-001, SC-001, SC-003, SC-004.

4 · Phase 3b — US2 · The coverage report

Tests (write & fail first)

Coverage unit tests — correct proportion of active decisions with a rule, a warning on the neither-checked-nor-excused, a warning on a past-review-by, and determinism under a pinned clock (SC-002). packages/core/test/guardrail.coverage.test.ts

Implementation

coverageFindings + proportion — count active decisions with ≥1 rule vs excused vs neither; emit warnings; compute the proportion. Injected clock for review-by. packages/core/src/guardrail/coverage.ts
Fold scanDecisionCoverage into validate + add adrs --coverage — warnings into the validate run (never blocking); the proportion printed by the report flag on 113's command. packages/cli/src/commands/validate.ts
Exercise coverage end-to-end — run spectastic adrs --coverage on a fixture corpus; assert the printed proportion and that validate emits the two warnings. Entry point: spectastic adrs --coverage.

Closes FR-005, SC-002, NFR-002.

5 · Phase 4 — Polish

Build + full guardrail suite — rebuild core+cli, run the guardrail tests green, typecheck all packages. packages/core/test/
