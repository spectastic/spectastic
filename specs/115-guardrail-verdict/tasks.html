Rule-shape extension → US1 native detect + compose + persist (tests then code, then exercise via spectastic verdict --changed) → US2 SARIF ingest → polish. Each story closes its conformance first.

3 · Phase 3a — US1 · Native detectors + verdict composition

Tests (write & fail first)

Verdict unit tests — content detector (pattern outside allowed zone → file:line), path detector (deny glob), composition {decision,rule,reason,file:line}, persistence shape, determinism under a pinned clock (SC-001, SC-004, NFR-002). packages/core/test/guardrail.verdict.test.ts
No-exec import-graph guard — the verdict kernel's transitive imports carry 0 model, 0 network, and 0 child-process/exec modules (SC-003). packages/core/test/guardrail.verdict.no-exec.test.ts

Implementation

verdictFor + native detectors + compose — retrieve governing decisions (113), run content + path detectors over the changed files, compose each violation; return an any-violation flag. packages/core/src/guardrail/verdict.ts
Persist the verdict JSON — reconstructable record beside the retrieval log; injected clock. packages/core/src/guardrail/verdict-log.ts
The verdict CLI — --changed <paths> else git diff --cached HEAD; --enforcer-output; write the artifact; exit non-zero on any violation; wire in index.ts. packages/cli/src/commands/verdict.ts
Exercise the native verdict end-to-end — a fixture changed file with a forbidden pattern outside its zone; spectastic verdict --changed exits non-zero naming decision + rule + file:line, and the verdict.json reconstructs from disk. Entry point: spectastic verdict --changed.

Closes FR-001, FR-002, FR-003, FR-005, FR-006, NFR-001, NFR-002, SC-001, SC-003, SC-004.
