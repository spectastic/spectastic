Status Draft Spec 003-init-node-port Plan plan Branch 003-init-node-port Created 14 Jun 2026 Read time

29 tasks across five phases. Setup wires @clack/prompts and the prebuild bundle copy; Foundational adds the bundle resolver and the FileWriteDecision type that every story consumes; US1 ships the empty-directory init (the smallest demoable); US2 adds the conflict-prompt loop; US3 adds --force and non-TTY refusal; Polish retires the Python implementation and flips 001-cli to superseded. Tasks marked [P] can run in parallel. Tests for each story MUST be written and failing before its implementation tasks start.

1 · Execution strategy

Drive US1 end-to-end first (empty-dir init works). Demo the smallest valuable slice, then layer US2 (prompts) and US3 (--force). Polish — including the Python deletion — comes only after all three stories pass tests.

Setup → Foundational → US1 → US2 → US3 → Polish. Each story closes its conformance before the next opens. Recommended for solo work; lowest coordination cost.

One contributor on Setup + Foundational solo; after T-012 lands, one contributor per user story. Coordinate at packages/cli/src/commands/init.ts (the action handler that wires everything together).

4 · Phase 3a — US1 · New-project author bootstraps spectastic P1

Empty-dir init writes the 16-file lifecycle. The smallest demoable.

Tests (write & fail first)

Unit test for write.ts: given a plan with all "write" actions, creates the files at the right paths with byte-identical content vs the bundle packages/cli/test/init/write.test.ts
Smoke integration: spawn compiled CLI in os.tmpdir() empty subdir; assert 16-file structure, exit 0, summary line format (FR-001, FR-002, FR-006, FR-007) packages/cli/test/init/smoke.test.ts

Implementation

Plan builder: walk bundle inventory (from T-011); for each source, compute CWD-relative destination + check existence; produce FileWriteDecision[] with action="write" for all (no conflicts in US1 path) packages/cli/src/commands/init/plan.ts
Writer: execute FileWriteDecision[] sequentially; mkdir -p parents; copy source → destination via fs.copyFile (FR-008 atomicity satisfied by plan-then-write) packages/cli/src/commands/init/write.ts
Init action handler: commander registration + flow (bundle → plan → write → summary); no prompt path yet (US2 adds it) packages/cli/src/commands/init.ts
Wire init alongside validate in the commander entry; usage shows both subcommands packages/cli/src/index.ts
Run prebuild once, build the CLI, verify T-102 smoke passes end-to-end packages/cli/_bundled/ + dist/

Closes FR-001, FR-002, FR-006 (exit 0/1 paths), FR-007, FR-008, FR-009, NFR-001, NFR-002, NFR-003, partial SC-001 (empty-dir branch).

5 · Phase 3b — US2 · Repeat-init author isn't surprised P1

Conflict prompts make re-init safe.

Tests (write & fail first)

Unit test for prompt-decision: given a plan with conflicts + simulated answers (y, N, a, s, mixed), mutates plan to correct action values packages/cli/test/init/prompt.test.ts
Smoke integration: existing-file tmp dir, programmatically drive prompts (y / N / a / s flows), assert correct files written/skipped/overwritten and summary counts packages/cli/test/init/smoke.test.ts (extend)

Implementation

Prompt loop: for each conflict in the plan, use @clack/prompts select with [y/N/a/s] options; mutate plan in-place (y→overwrite, N→skip default, a→all-remaining overwrite, s→all-remaining skip); propagate Ctrl-C as cancel (writer not called) packages/cli/src/commands/init/prompt.ts
Wire prompt loop into init.ts action: if any plan entry has a pre-existing destination, run prompt loop between plan and write phases packages/cli/src/commands/init.ts (modify)

Closes FR-003; remaining SC-001 coverage (conflict branches); partial SC-002 (y/N/a/s matrix).

6 · Phase 3c — US3 · CI script idempotent bootstrap P2

--force + non-TTY refusal.

Tests (write & fail first)

Unit test: --force flag causes the prompt loop to be skipped; plan mutates with all conflicts → "overwrite" automatically packages/cli/test/init/prompt.test.ts (extend)
Smoke integration: spawn CLI without TTY (stdin redirected from /dev/null) against existing-file tmp dir, assert exit 2 and error message names --force; then re-run with --force and assert exit 0 packages/cli/test/init/smoke.test.ts (extend)

Implementation

Add --force option to the init commander; thread the boolean through to the prompt module packages/cli/src/commands/init.ts (modify)
TTY + force gating in prompt.ts: if --force, skip prompts and mark all conflicts "overwrite"; else if !process.stdin.isTTY and conflicts exist, refuse with exit 2 and a stderr message naming --force packages/cli/src/commands/init/prompt.ts (modify)

Closes FR-004, FR-005, FR-006 (exit 2 branch); completes SC-002.
