Spectastic CLI — spectastic init

Ordered, parallelizable work. Tests precede implementation. Drive through with /spectastic.implement — one task per invocation.

Status Draft Spec 001-cli Plan plan Branch main Created 12 Jun 2026 Read time

33 tasks across five phases. Setup → Foundational → US1 (empty-dir init) → US2 (prompt-on-conflict) → US3 (--force + non-TTY refusal) → Polish. Tasks marked [P] can run in parallel — distinct files, no in-flight dependency. Each user story opens with failing tests before any implementation task starts. Closes all 9 functional requirements + 3 non-functional + 3 success criteria; traceability listed in each story's closing <spec-note>.

1 · Execution strategy

Solo work; risky-only-on-paper feature. Drain Setup + Foundational + US1 first to ship the empty-dir demo path end-to-end. Iterate to US2 (prompt) and US3 (--force) only after US1 is verified by a green test run in a tempdir. Polish closes nothing the user cares about; do it last.
