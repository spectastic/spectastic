23 tasks across five phases. Setup → Foundational → US1 · US2 · US3 → Polish. Tasks marked [P] can run in parallel — different files, no dependency. Tests for a story MUST be written and failing before its implementation tasks start.

1 · Execution strategy

Implement US1 (one profile → three files, greenfield) end-to-end and verify it in a browser before US2/US3. US1 is the smallest demoable (SC-001).

Setup → Foundational → US1 → US2 → US3 → Polish. Each story closes its conformance before the next opens.

After Foundational, US2 (dial + prompt) and US3 (re-run/upgrade) are independent; coordinate at the composer and marker seams via the plan, not chat.

2 · Phase 1 — Setup

Author the profiles manifest — the four profiles as data (name, five axis values, ordered principle preset blocks with stable P-* ids, AGENTS.md section fragments) profiles.json
Author the AGENTS.md base skeleton — command-first sections (overview · setup/build/test · code style · testing · "done" criteria) with fill-in placeholders templates/agents/base.md
Author the thin CLAUDE.md pointer — a ~5-line file pointing at AGENTS.md templates/agents/claude-pointer.md
Bundle the new data + templates — add profiles.json and templates/agents/ to the init inventory and the prebuild copy packages/cli/src/commands/init/bundle.ts

3 · Phase 2 — Foundational

Shared infrastructure no story can ship without.

Add content-based writes — optional content?: string on FileWriteDecision; executeWrites writes it via writeFile, else copyFile(source) (D-002) packages/cli/src/commands/init/{types,write}.ts
Load + resolve profiles — read bundled profiles.json, fail-safe on missing/malformed, expose resolveProfile(name) (D-001) packages/cli/src/commands/init/profiles.ts
Build the composer — compose principles.html (base + additive blocks before the sentinel), AGENTS.md, and CLAUDE.md into content-based decisions (D-003, D-004) packages/cli/src/commands/init/compose.ts
Read/write the profile marker — .spectastic/profile.json = {profile, schema} (D-005) packages/cli/src/commands/init/marker.ts
