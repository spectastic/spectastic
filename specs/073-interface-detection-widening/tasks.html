19 tasks across five phases. Two hard orderings. The amendment to 042's FR-014 is task one — that spec records today's narrow detection as an accepted ceiling, so code must not cross it first. And the regression set pinning every current verdict is written before anything widens, because NFR-002 allows at most 0 projects to change verdict.

1 · Execution strategy

US1 alone — an event-driven service finally gets asked for a contract — is the headline value, but shipping it without US3's declaration precedence means warning consumers as if they were publishers.

Amendment → Setup → Foundational → US1 → US2 → US3 → Polish. Recommended. US1 and US2 both edit detect.ts tables, so sequencing avoids collisions.

Workable in two after the amendment: the broker-signal half (US1) and the contract-path half (US2) touch different tables. US3's precedence rule must follow both.
