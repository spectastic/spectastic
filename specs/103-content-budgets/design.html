Design · 103-content-budgets

Copy is part of the spec

How we will build it.

Status Accepted Spec 103-content-budgets Owner Brian Corbin · @briancorbinxyz Branch spec/visual-slice-095-098 Created 13 Aug 2026 Read time

Budgets per element class, refusals with reasons and contexts, and a message shape referenced rather than restated. The load-bearing decision is a refusal: a budget is never checked against running text, because the copy lives in a localisation system or a person's draft and a check that read only what it could reach would report clean while the rest overflowed. Voice stays prose, because it is the part that genuinely resists structure.

6 · Approach

Three declarations, all pure. A budget carries a number, a unit and the element class it constrains, optionally scoped to a source language. A refusal carries the string, a reason and optionally the context it applies in. A message shape is declared once and referenced by the states that use it. Voice is prose and gets no structure at all.

The design is mostly about what it refuses to do. FR-003 makes it a requirement that a budget is never checked against running text — not a limitation recorded in a caveat, because the difference matters: a partial check that read only the strings it could reach would report clean while the rest overflowed, which is a false negative that reads as diligence. And voice gets no schema, because inventing one produces something nobody can satisfy and no check can read — the tenth-taxonomy mistake this family already refused once.

7 · Alternatives considered

Whether to check budgets against real copy. Scored 1–5 on whether the check can be trusted, how much it costs, and whether a clean result means anything.

The partial check loses on the only column that matters. A green result on the strings the tool happened to find is indistinguishable from a green result on all of them, and a warning next to it does not fix that — people read the colour, not the caveat.

8 · Decisions

D-001 · A budget is never checked against running text, and that is a requirement

Status
Accepted
Context
The copy a budget constrains lives in a localisation system, a database, or a draft nobody has committed. Nothing in this vocabulary can see it.
Decision
Stated as FR-003 rather than left as a caveat, so a later slice cannot quietly add a partial check and call the budget enforced.
Consequences
+ A clean result never means "clean on the strings we found", which is the failure a partial check could not avoid. + Nothing has to be built. − The budget constrains nobody, and its whole value rests on being read at the moment somebody writes. That is a real weakness and it is the reason the number is required to be a number.

D-002 · A budget carries a unit, and one without a number is reported

Status
Accepted
Context
Characters and words give different answers, and a bare number silently picks one. The same problem was solved an hour earlier for a motion offset, where a number could have been milliseconds or frames.
Decision
Number and unit are both required, and both render.
Consequences
+ "Short" records an opinion and constrains nothing; a number and a unit constrain something. + A project that counts words rather than characters says so without the number changing meaning. − Slightly more to write for the common case.

D-003 · Voice stays prose and gets no schema

Status
Accepted
Context
The annotation vocabulary already names content as having no accessibility analogue, and the survey behind this family refused to mint a tenth taxonomy for exactly this kind of material.
Decision
Voice guidance is prose. No structure, no check.
Consequences
+ Nothing is invented that nobody can satisfy and no check can read. − The most-quoted half of a content style guide is the half with no machine coverage, which is honest rather than satisfying.

11 · Complexity tracking

A requirement that forbids building something. FR-003 is unusual: most requirements say what must exist. This one exists so that a later slice cannot add a partial check and present a green result as enforcement — the failure mode is subtle enough that it needs a requirement to stop it rather than a note.

12 · Open questions

None outstanding. The decision that could have gone either way — whether to check budgets against the strings the tool can reach — is settled against, because a green result on some of the copy is indistinguishable from a green result on all of it, and a warning beside it does not help: people read the colour.
