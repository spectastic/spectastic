Add destination-state-aware behaviour (cite P-6)

Applied

1 · Intent

One of four mechanical cascades from the just-applied P-6 elevation. Where 008's cascade MODIFIES an existing FR, 009's adds a new one: 009's spec never explicitly governed the destination-existence decision — that behaviour lived only in the CLI subcommand's blanket-refuse path. P-6's ratification makes it a first-class concern; ADD FR-012 to anchor it.

2 · Scope

In scope

  • ADD FR-012 gating the verb's destination-existence behaviour on <spec-status> per P-6.
  • Hotfix packages/core/src/commands/tasks.ts + packages/cli/src/commands/tasks.ts to inspect destination status before refusing.

Out of scope

  • Re-deriving P-6 in the FR body. The FR is a one-line scope statement citing the principle.
  • The tasks-file's task ID stability concerns (stable T-NNN across re-runs) — those are already governed by FR-006's deterministic-computation rule; no change needed.

3 · Approach

Single ADD. FR-012 sits at the end of the Functional block, after FR-011. It explicitly governs the verb's destination-existence behaviour by reference to P-6: Draft destinations honour in-place edit (preserve T-NNN IDs per FR-006; append a one-line changelog entry); past-Draft destinations refuse with a typed error pointing at /spectastic.propose; --force override stays as a past-Draft escape hatch.

4 · Deltas

The verb's behaviour against an existing destination tasks.html MUST gate on the destination's <spec-status> per P-6: a Draft destination MUST be edited in place (preserve T-NNN IDs per FR-006; append a one-line <spec-changelog> entry); a past-Draft destination (Accepted, In Review, Superseded, Deprecated, Blocked) MUST be refused with a typed error pointing at /spectastic.propose. A --force override MAY bypass the past-Draft refuse, but invoking it MUST emit a one-line warning that the operation skips the change-management surface.

Rationale

Cascade of 009/T-001: blanket refuse-if-exists conflated Draft with past-Draft destinations. P-6 ratified the asymmetry; this FR makes the verb honour it explicitly. The behaviour was previously implicit in the CLI subcommand only; surfacing it as a spec-line FR closes the regen test (next LLM session reproducing the verb from the spec will inherit the gate).

5 · Risk register

Adversarial pass deliberately opted out (--no-adversarial). Substance exhausted at parent P-6 proposal; this is a mechanical cascade.
