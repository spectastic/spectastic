Design · 034-effort-auto

Auto effort

How we will build it.

Status Accepted Spec 034-effort-auto Owner Brian Corbin · @briancorbinxyz Branch 034-effort-auto Created 09 Jul 2026 Read time

Add a pure resolveEffort(requested, signal, floor) to the 033 decider module: when requested='auto' it derives a level from a verb-agnostic risk signal (irreversible / breadth), clamped to a floor; an explicit level short-circuits. Propose builds its signal from its existing predicates and passes the resolved concrete level (plus the reason) into decide. auto becomes the default. Low risk — it is one pure function plus a wiring change.

4 · Approach

New decider/auto.ts: a RequestedEffort = EffortLevel | 'auto', an EffortSignal = { irreversible: boolean; breadth: number }, and a pure resolveEffort(requested, signal, floor='low'): { level, reason } — explicit short-circuits; auto maps irreversible→high, breadth≥2→medium, else floor, then clamps to ≥ floor. Propose builds the signal from its deltas, resolves, and passes the concrete level into decide; the reason joins the verdict grounds. ProposeInput.effort and the CLI --effort accept auto, and auto is the default when nothing is set.

5 · Decisions

D-001 · A pure resolver upstream of decide()

Status
Accepted
Context
decide() reads a concrete cfg.effort (decider.ts); auto is a pre-step, not a decide change.
Decision
resolveEffort(requested, signal, floor) in decider/auto.ts — pure, deterministic (NFR-001). Explicit wins (FR-004); auto derives from the signal (FR-001/002) clamped to the floor (FR-003).
Consequences
+ No change to 033's panel machinery; trivially testable.
− A new RequestedEffort type alongside EffortLevel.

D-002 · Verb-agnostic signal; propose supplies the first

Status
Accepted
Context
Propose already computes irreversible + breadth (propose.ts); other verbs come with 035.
Decision
The signal is a plain { irreversible, breadth } struct a verb fills in — no per-verb registry needed in v1; propose maps its predicates to it. FR-006's "unknown verb → floor" is the default when a caller passes a null signal.
Consequences
+ One heuristic, reused; no coupling to a verb registry.
− 035 threads the signal for each new verb it wires.

D-003 · Floor is a config knob, default low

Status
Accepted
Context
loadDeciderConfig already reads the decider section.
Decision
Add optional decider.floor (default low), passed into resolveEffort. Validated like the other fields.
Consequences
+ Tunable minimum rigour (FR-003).
− One more optional config key.
