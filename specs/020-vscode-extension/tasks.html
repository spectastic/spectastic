Status Accepted Spec 020-vscode-extension Plan plan Branch 020-vscode-extension Created 2026-06-21 Read time

37 tasks across five phases. Setup → Foundational → User stories (US1·US2·US3) → Polish. Tasks marked [P] can run in parallel — different files, no dependency. Tests for a story MUST be written and failing before its implementation tasks start. Per the plan's behaviour-first strategy, every interactive piece gets a Playwright spec that runs the JS and asserts behaviour, not just structure.

1 · Execution strategy

Implement US1 end-to-end (the canvas renders and stays live). Verify it in a browser, then add US2 (open) and US3 (compact card · attention · stale). Recommended — this is solo, first-of-its-kind work with a real unknown (the D-005 webview-CSP spike), so prove the riskiest seam before widening.

Setup → Foundational → US1 → US2 → US3 → Polish. Each story closes its conformance before the next opens.

One engineer per user story after Foundational. Coordinate at shared seams (the LifecycleGraph message protocol, node.ts) via the spec, not Slack.
