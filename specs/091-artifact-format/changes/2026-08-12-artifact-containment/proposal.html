Wide content contains itself

An artifact that scrolls sideways is unreadable on the device most people first open it on.

Wide content contains itself

Proposed

1 · Intent

The format requirements govern budgets, bands and copy. None of them says an artifact must stay readable at a narrow viewport, and the result was measurable: 154 of 227 artifacts overflowed at 390 px. The fix has landed — a definition list now collapses below 700 px, long unbreakable tokens wrap, tables carry scroll containers, and the templates and the verify generator no longer propagate the defect. The count is 8.

What has not landed is the reason any of it stays true. Without a requirement, the next bare table is nobody's defect, and the estate drifts back. This adds the rule the work already satisfies.

2 · Scope

In scope

  • A requirement that wide content scrolls inside its own container rather than the page.
  • Naming the viewport the rule is measured at, so it is checkable rather than a matter of taste.

Out of scope

  • A validate rule enforcing it — worth having, and it needs a browser to measure, which the schema engine deliberately does not have.
  • The 8 artifacts that still overflow for individual content reasons; each is a separate small fix.

3 · Approach

One added requirement at should tier rather than must. The honest reason is enforcement: the check needs layout, and every mechanism this project trusts for a must is static. A should that the whole estate visibly meets is worth more than a must nothing can verify — and if a measuring harness later exists, raising the tier is a one-line proposal.

4 · Deltas

An artifact SHOULD contain its own wide content: at a 390 px viewport the page SHOULD scroll vertically only, with tables, code blocks, diagrams and definition lists scrolling or reflowing inside their own bounds.

Rationale

Measured at 390 px, 154 of 227 artifacts scrolled sideways, worst at 752 px — a document that cannot be read on a phone without panning. The tier is should because verifying it needs layout, which no static check has; the estate meets it at 219 of 227 today, so the rule records a standard already kept rather than one aspired to.

5 · Risk register

The adversarial pass did not trigger: one added should-tier requirement, no removal, one topic prefix. Recorded rather than silently skipped.

6 · Tasks

  • Wrap the templates' tables and theme the architecture sketch templates/

7 · Open questions

None outstanding. The tier was the only real choice and it is argued in §3; the measurement method — the widest element whose nearest scrollable ancestor is the page — is recorded in inbox I-058 along with the two diagnoses it corrected.
