Decider rollout

How we will build it.

Status Accepted Spec 035-decider-rollout Owner Brian Corbin · @briancorbinxyz Branch 035-decider-rollout Created 09 Jul 2026 Read time

Re-express slice/panel.ts's panelScore over the Decider: size the scorers from effortToDepth(effort).voters with a high floor (≥ 3, preserving 029), fan them out with 032's mapPool instead of the serial loop, and consolidate onto the Decider's median. Back-compat: an explicit scorer count still wins. Low risk — a delegation + a floor + a concurrency swap, guarded by 029's existing panel tests.

3 · Approach

panelScore(children, ctx, opts?) gains a config path: when no explicit count is given it resolves one via resolveEffort('auto', { irreversible: false, breadth: children.length }, 'high') → effortToDepth(level).voters (≥ 3, ≤ 5). The scorer loop becomes a mapPool fan-out under the cap; per-RICE-input aggregation calls the Decider's median, and the slicer's private median is deleted (medianRice keeps its name but delegates). An explicit numeric opts short-circuits to exactly that count (029 back-compat).

4 · Decisions

D-001 · panelScore sizes from the effort table, floored high

Status
Accepted
Context
panelScore hard-codes scorers=3 (panel.ts:40); 029 needs ≥ 3.
Decision
Resolve the count from effortToDepth(effort).voters via resolveEffort with floor high (FR-001/002/003). An explicit numeric arg overrides (FR-006).
Consequences
+ One dial across checkpoints; auto works here.
− panelScore signature gains an optional config form.

D-002 · Concurrent scorers via 032's mapPool

Status
Accepted
Context
The scorer loop is serial (panel.ts:46); 032 shipped a bounded, input-ordered pool.
Decision
Replace the loop with mapPool(range(N), scoreOnce, N) — the votes still aggregate deterministically (median is order-independent) (FR-004).
Consequences
+ Faster ranking; reuses a proven primitive.
− A cross-module import (core triage → core slice); both in-package.

D-003 · One median

Status
Accepted
Context
Two identical medians exist (decider/panel.ts + slice/panel.ts).
Decision
The slicer imports the Decider's median; its private copy is deleted. medianRice keeps its name, calling the shared median per input (FR-005, SC-004).
Consequences
+ 033's numeric arbitration gets a real consumer; one source of truth.
− none material.
